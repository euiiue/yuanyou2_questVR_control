## 安装 ROS2/colcon 时 dpkg 覆盖冲突

报错：

```bash
在处理时有错误发生：
 /tmp/apt-dpkg-install-*/044-python3-catkin-pkg-modules_1.1.0-2_all.deb
 /tmp/apt-dpkg-install-*/090-python3-rospkg-modules_1.6.1-1_all.deb
E: Sub-process /usr/bin/dpkg returned an error code (1)
```

真实冲突行在 `/var/log/apt/term.log`：

```bash
正试图覆盖 /usr/lib/python3/dist-packages/catkin_pkg/__init__.py，它同时被包含于软件包 python3-catkin-pkg 0.4.24-2
正试图覆盖 /usr/lib/python3/dist-packages/rospkg/__init__.py，它同时被包含于软件包 python3-rospkg 1.3.0-1
```

原因：

Ubuntu 源里旧的 `python3-catkin-pkg` / `python3-rospkg` 已经装过，ROS2 源里的新包把 Python 模块拆成了 `python3-catkin-pkg-modules` / `python3-rospkg-modules`，dpkg 默认不允许直接覆盖旧包文件。

修复命令：

```bash
sudo apt-get -o Dpkg::Options::="--force-overwrite" install -y \
  python3-catkin-pkg \
  python3-catkin-pkg-modules \
  python3-rospkg \
  python3-rospkg-modules

sudo apt --fix-broken install -y
sudo dpkg --configure -a
```

验证：

```bash
source /opt/ros/humble/setup.bash
colcon --version
ros2 --help
```

如果 `apt --fix-broken install` 继续提示同样的覆盖冲突，再执行：

```bash
sudo apt-get -o Dpkg::Options::="--force-overwrite" --fix-broken install -y
sudo dpkg --configure -a
```
